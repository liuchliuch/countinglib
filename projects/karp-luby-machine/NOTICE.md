# Source reuse notice

This package adds new proofs and finite-machine clients. Existing R1/F1/H1
mathematical and machine definitions are imported from their unique local
providers. Their provenance, upstream licenses/notices and source snapshots
remain with those providers; no original upstream source blob is duplicated here.

- `../karp-luby`: executable general-DNF program, codecs, finite probability and PAC.
- `../foundations`: finite-alphabet PolyTime and machine-composition interface.
- `../holant-unified`: canonical actual binary fraction-normalization machine.
- `../holant-core`: shared six-module provider, inherited transitively.

See `DESIGN.md`, `notes/framing/result.json`, and
`reports/provider-sources.json` for declaration-level reuse and exact source hashes.
